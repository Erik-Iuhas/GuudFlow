# Plan, then edit

1. Write a todo list (the todo tool) of three to seven steps: what you will change, the test
   you will add or run, and how you will check each acceptance item.
2. Change only what the card asks for. No drive-by refactors, renames or reformatting of
   untouched code.
3. Follow the existing code's style, layout and names. Put new code where the design or the
   layout says it belongs.
4. Keep each step small and run the check command after the step that changes behaviour.
5. Tick the todo list as you go. Anything you leave undone goes in your summary.
